Что сделать?

Выберите действие. Установка и откат защищены A/B-резервом: пока новая система не поднимется, прежняя остаётся целой и загрузится обратно.

Проверка окружения

Прошивка работает только на Linux. На Windows запускайте из-под WSL.

    Настройки

    Определяется автоматически. Проводной — надёжнее.
    По умолчанию — последний стабильный.
    SHA-256 должен совпадать с одобренным в профиле устройства.
    Wi-Fi и пароль установленной системы (необязательно)
    Оставьте пустым — Wi-Fi останется выключенным, пароль root не задан (для проводной проверки).
    Делает sysupgrade -b и восстанавливает конфиг на новой прошивке. Снимите галочку для чистой установки. Бэкап настроек в любом случае сохраняется на ваш компьютер.

    Подтверждение

    Безопасность

    • Сначала запустите пробный прогон: он только скачает и проверит образы, роутер не трогается.
    • Необратимая запись происходит только после явного подтверждения.
    • Единственная страховка на случай неудачной записи — доступ по UART. Не отключайте питание во время записи.
