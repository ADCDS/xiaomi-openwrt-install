# Обновление и восстановление Xiaomi AX3000T RD03v2

[English](maintenance.md) · **Русский** · [简体中文](maintenance.zh-CN.md) · [Português (Brasil)](maintenance.pt-BR.md)

Выполняйте команды на компьютере из папки репозитория. В Windows используйте `py -3` вместо `python3`. В примере проверки замените `12` индексом адаптера, подключённого к роутеру.

## Проверка после записи

Сообщение `sysupgrade уже запущен` означает, что повторять запись нельзя. То, что
роутер не нашёлся, само по себе не доказывает неудачу. Подключитесь к постоянной сети
или к LAN-порту кабелем и выполните **только проверку**, указав `resume.json` именно
этого запуска (путь напечатан установщиком):

```powershell
py -3 install.py --verify-only ".\install-ДАТА-ВРЕМЯ\resume.json" --verify-interface 12
```

Не используйте манифест другого роутера или другой установки.

### Забыт пароль постоянной сети Wi-Fi

Подключитесь к **LAN-порту** кабелем, получите адрес автоматически и откройте
`http://192.168.1.1`. В LuCI: **Network → Wireless → Edit → Wireless Security**,
задайте новый пароль, затем **Save & Apply**. Заводской сброс не нужен.

## После установки

- Если в логе было `root password=unset`, задайте пароль администратора:
  **System → Administration**.
- Проверьте страну и настройки безопасности Wi-Fi.
- Сохраните настройки: **System → Backup / Flash Firmware → Generate archive**.
- Храните папку `install-*` в закрытом месте. В `firstboot.tar.gz` может находиться пароль Wi-Fi, а в `resume.json` — данные устройства и секреты сеанса. В Windows выберите папку без общего доступа. Перед публикацией журнала удалите конфиденциальные данные.

## Обновление установленной системы

```sh
python3 updater.py --root-password 'ВАШ_ПАРОЛЬ'
```

По умолчанию `updater.py` сохраняет резервную копию в закрытую папку `update-*` и обновляет OpenWrt с сохранением настроек. Для входа по SSH нужен доступ по паролю. С `--dry-run` программа скачивает и проверяет образы без подключения к роутеру.

Между релизами v2 обновление выполняется через `sysupgrade` из установленной системы. Если `sysupgrade -T` сообщает только об ошибочном запрете обновления в версиях v2.0.0–v2.1.2, программа применяет `-F`. Другие ошибки останавливают обновление. При переходе с v1.x или на v1.x используется RAM-установщик. Ключ `--via-ram-installer` выбирает этот путь и между версиями v2, с переформатированием обоих разделов UBI. См. [ручную процедуру (на английском)](https://github.com/ADCDS/openwrt-xiaomi-ax3000t-rd03v2/blob/main/docs/no-uart-reflash.md).

| Параметр | Назначение |
|---|---|
| `--release ТЕГ`, `--offline` | Выбор версии. Для работы без сети нужен проверенный кэш образов с указанным тегом. |
| `--no-keep-settings`, `--verify-interface ИНТЕРФЕЙС` | При сбросе настроек для финальной проверки нужен проводной интерфейс. При обновлении по кабелю по умолчанию используется интерфейс, подключённый к роутеру. |
| `--wifi-ssid ИМЯ` | Укажите постоянную сеть при продолжении из RAM-установщика с финальной проверкой по Wi-Fi. |
| `--device`, `--images`, `--outdir` | Выбор профиля устройства, кэша образов и выходной папки. |
| `--yes` | Заранее подтвердить операции. |

В OpenWrt установлено одно ядро. При переходе в RAM оно перезаписывается перед перезагрузкой. Если процесс прервался и RAM-установщик доступен, продолжите с `--config-backup`, указав сохранённый архив. Для восстановления после незавершённой записи может потребоваться UART или заводское восстановление по TFTP. Применяйте `--recover-stale-lock` только после проверки неактивной блокировки.

## Возврат на заводскую прошивку

Выберите самый свежий образ из [списка одобренных заводских прошивок RD03v2 (на английском)](technical.md#getting-the-images). Загрузчик принимает только версии не старше последней заводской прошивки, работавшей на этом роутере.

Запустите команду, пока на роутере работает OpenWrt.

```sh
python3 revert.py --device rd03v2 /путь/к/заводскому-образу.bin --interface ИНТЕРФЕЙС
```

В Windows: `py -3 revert.py ...`, этот путь на реальном роутере ещё не проверялся.
Дополнительные параметры: `--transport wired`, `--root-password ПАРОЛЬ`, `--dry-run`.
Подтверждение стирания нужно ввести словом `RESTORE` латиницей.

`revert.py` проверяет заводской образ, скачивает образы RAM-системы, переводит роутер
в RAM, восстанавливает заводскую прошивку и дожидается ответа заводской системы, сообщая её
hardware, ROM и ждёт ли мастер настройки.
Для возврата используйте его, а не повторный запуск прошивки: после `sysupgrade`
заводской A/B-резерв уже стёрт (см. [NOTICE](../NOTICE)).
