# xiaomi-openwrt-install

[English](README.md) · **Русский** · [Техническая документация (English)](docs/technical.md)

Установка OpenWrt на поддерживаемые роутеры Xiaomi без UART и пайки, а также
возврат установленного роутера на одобренный заводской образ. Работает из Linux
и из Windows 10/11 без WSL.

Установщик получает root через
[задокументированную цепочку уязвимостей `cab_meshd`](https://github.com/ADCDS/xiaomi-ax3000t-cabmeshd-disclosure#combined-v1--v2-capuci-exploit),
проверяет плату, NAND и разметку, скачивает образы OpenWrt для вашего устройства,
загружает временную RAM-систему и записывает постоянную прошивку.

> Прочитайте [NOTICE](NOTICE). Используйте установщик только на своём роутере.

Запросы и инструкции установщика выводятся на русском, если язык системы русский.
Язык можно задать явно: `--lang ru` или `--lang en`. Низкоуровневая диагностика
остаётся на английском: так её проще приложить к сообщению об ошибке.

## Что проверено

| Сценарий | Статус |
|---|---|
| Linux, заводские прошивки 2.0.28 и 2.0.12 | Основной сценарий, проверен на реальном роутере |
| Windows 10, Wi-Fi, заводская 2.0.28, релиз v1.14 `standard` | Проверено на реальном роутере 11 октября 2026 г. ([alexsys87](https://github.com/alexsys87/xiaomi-openwrt-install)) на более ранней версии кода |
| Windows, текущая версия кода и релизы v2.x | Автоматические тесты; **на реальном роутере ещё не проверялось** |
| Windows, установка по кабелю | Автоматические тесты; **на реальном роутере ещё не проверялось** |
| Windows, возврат на заводскую прошивку (`revert.py`) | Автоматические тесты; **на реальном роутере ещё не проверялось** |

Если вы устанавливаете из Windows, держите под рукой компьютер с Linux или
USB-UART адаптер на случай сбоя. Сообщите о результате в
[Issues](https://github.com/ADCDS/xiaomi-openwrt-install/issues), особенно если
всё прошло успешно: это поможет обновить таблицу.

Поддерживается только Xiaomi AX3000T **RD03v2** (Qualcomm IPQ5018). Другие модели
установщик отклоняет. Не переносите эту инструкцию на них.

## 1. Подготовка

- Обеспечьте стабильное питание роутера. Не отключайте его во время записи.
- Сохраните нужные заводские настройки: сброс удалит конфигурацию и пароли.
- Изолируйте подключение: к заводской и временной сети не должны подключаться
  посторонние устройства. Пароль временной сети общеизвестен, а у root во
  временной RAM-системе пароля нет.
- Отключите VPN и другие сети, чьи адреса могут совпасть с адресами роутера.

Скачайте репозиторий и откройте терминал в его папке:

```sh
git clone https://github.com/ADCDS/xiaomi-openwrt-install.git
cd xiaomi-openwrt-install
```

### Linux

Нужен Python 3.9 или новее:

```sh
sudo apt install sshpass openssl
```

### Windows 10/11

Установите Python 3.9 или новее с
[python.org](https://www.python.org/downloads/windows/), включая launcher `py`.
Можно скачать ZIP репозитория вместо `git clone`. Откройте PowerShell в папке с
`install.py` и установите зависимости **пока есть доступ к Интернету**:

```powershell
py -3 -m pip install -r requirements-windows.txt
py -3 install.py --list-interfaces
```

`--list-interfaces` показывает индекс, имя и тип каждого адаптера. Подставляйте
свой индекс или имя вместо `12` в командах ниже. Если в имени есть кириллица или
пробелы, проще использовать индекс; после изменения адаптеров он может поменяться.

WSL, `sshpass`, `nmcli` и отдельная установка OpenSSL не нужны. Не отключайте IPv6
на выбранном адаптере: поиск роутера после перезагрузки использует IPv6 link-local.

Запускайте установщик от обычного пользователя; права администратора нужны только
для правила брандмауэра (см. [раздел 6](#обратное-подключение-не-приходит-брандмауэр-windows)).
В Windows вместо `python3` используйте `py -3`. Из командной строки (cmd) можно
запускать `install.cmd` с теми же параметрами, в PowerShell: `.\install.cmd`.

## 2. Образы и Интернет

Заводская Wi-Fi сеть Xiaomi может не давать выхода в Интернет, поэтому **заранее**
скачайте и проверьте образы. Команда не обращается к роутеру:

```powershell
py -3 install.py --transport wifi --dry-run
```

В Linux то же самое: `python3 install.py --transport wifi --dry-run`. Для установки
по кабелю уберите `--transport wifi`.

По умолчанию выбирается последний опубликованный релиз
[порта для RD03v2](https://github.com/ADCDS/openwrt-xiaomi-ax3000t-rd03v2) с
аппаратным ускорением NSS. В выводе будет строка `selected ... from release vX.Y.Z`:
запомните этот тег. Для работы без Интернета нужен явный тег и скачанные образы:

```powershell
py -3 install.py --release vX.Y.Z --transport wifi --offline --dry-run
```

Сборка без NSS есть только в последнем релизе линейки v1.x:
`py -3 install.py standard --release v1.14`.

## 3. Сброс и подключение

1. Выполните аппаратный сброс кнопкой Reset.
2. Подключитесь к порту **LAN** (не WAN) кабелем или к открытой заводской сети
   Wi-Fi вида `minet_rd03_XXXX`.
3. **Не проходите мастер настройки Xiaomi** ни в браузере, ни в Mi Home.
   Автоматически открывшуюся страницу можно закрыть.
4. Отключите VPN и лишние подключения. При установке по Wi-Fi отсоедините кабель
   и не позволяйте компьютеру переключиться на домашнюю сеть.
5. Проверьте адрес: должен быть `192.168.31.x`, а `http://192.168.31.1` должен
   открываться. Сообщение «Без доступа к Интернету» здесь нормально.

## 4. Установка

```sh
python3 install.py
```

В Windows, указав свой адаптер:

```powershell
py -3 install.py --interface 12 --configure
```

Без Интернета добавьте тег из раздела 2: `--release vX.Y.Z --offline`.

Установщик сам определит способ подключения; переопределить его можно через
`--transport wired` или `--transport wifi`, а интерфейс через `--interface`.
Перед каждой необратимой записью он спросит подтверждение. Отвечать нужно словом
`YES` **латиницей**.

Вопросы при `--configure` (при установке по Wi-Fi они обязательны и без этого
параметра, кроме пароля root):

| Вопрос | Что вводить |
|---|---|
| Пароль root | Новый пароль администратора OpenWrt. Лучше не оставлять пустым. |
| Имя сети Wi-Fi (SSID) | Имя постоянной сети, например `Xiaomi`. |
| Пароль Wi-Fi | 8–63 печатных символа ASCII: латиница, цифры, обычные знаки. Без кириллицы и эмодзи. |
| Код страны | Страна фактического использования, например `RU`. |

Пароли при вводе не отображаются. Сохраните их: пароль Wi-Fi и пароль root не
связаны между собой, и установщик пароль Wi-Fi не выводит.

Чтобы постоянный Wi-Fi остался выключенным, проведите финальную проверку по кабелю:

```sh
python3 install.py --transport wifi --interface WIFI_INTERFACE \
    --verify-interface ETHERNET_INTERFACE
```

## 5. Перезагрузки: три разные сети Wi-Fi

При установке по Wi-Fi не закрывайте окно терминала и не запускайте вторую копию
установщика. Роутер сменит сеть дважды, и подключаться к новым сетям нужно вручную.

1. **Заводская сеть Xiaomi.** После начальной настройки роутер перезагрузится, а
   установщик напишет `waiting up to 300s for tcp/19553`. Это обычное ожидание.
   Если компьютер отключился, подключитесь обратно к заводской сети.
2. **Временная RAM-система.** Когда заводская сеть пропадёт, подключитесь к:

   ```text
   SSID:   OpenWrt-RD03v2-Installer
   Пароль: rd03v2install
   ```

3. **Постоянный OpenWrt.** После записи временная сеть исчезнет. Подключитесь к
   сети, заданной при установке. Установщик ждёт роутер до 600 секунд и проверяет
   плату, постоянный overlay и размеры разделов.

В конце должно появиться `[+] OpenWrt установлен в NAND.`

После сообщений `flash-started` или «не отключайте питание» **не отключайте
питание, не сбрасывайте роутер и не запускайте этап прошивки повторно**.

## 6. Частые ошибки

Большая часть этого раздела взята из реальной установки из Windows 10
([alexsys87](https://github.com/alexsys87/xiaomi-openwrt-install)).

### Кириллица в имени интерфейса и `Interface ... not found`

В PowerShell имя при копировании может искажаться. Используйте числовой индекс из
`--list-interfaces`, например `--interface 12`.

### `--interface ... не совпадает с маршрутом к ...`

Система направляет трафик к роутеру через другой адаптер, а `--interface` не меняет
маршрутизацию. Установщик останавливается до использования одноразового триггера.
Подключитесь к нужному роутеру, отключите VPN и конкурирующую сеть, проверьте адрес
(`192.168.31.x`) и выберите правильный интерфейс.

### `V2 CAP path is unavailable (netmode=4)` и `inited=1`

Роутер уже настроен. Выполните заводской сброс, подключитесь к заводской сети и
**не проходите мастер Xiaomi**. Если ошибка повторяется после корректного сброса,
сохраните лог и создайте Issue; не пытайтесь обходить проверки.

### GitHub: `The handshake operation timed out`

Не удалось получить сведения о релизе по HTTPS. С роутером это не связано: в
заводской сети часто нет Интернета. Если образы скачаны заранее, используйте
`--release vX.Y.Z --offline` из раздела 2. Сам по себе `--offline` загрузку не
заменяет. Повторный сброс из-за этой ошибки не нужен.

### Пароль WPA2 не принимается

Переключите раскладку на английскую. Нужно 8–63 печатных символа ASCII. Эта проверка
выполняется до начала записи, поэтому роутер не затронут.

### Обратное подключение не приходит: брандмауэр Windows

Симптом: `root-доступ не получен` или `no root shell`. Сначала проверьте сеть и
маршрут. Если блокируется входящее подключение от роутера, разрешите `python.exe` и
нужные порты только от заводского адреса. Заводскую сеть Windows может считать
общедоступной, поэтому правила только для частных сетей может не хватить. В
PowerShell **от имени администратора**:

```powershell
$python = py -3 -c "import sys; print(sys.executable)"
New-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" -Direction Inbound -Action Allow -Program $python -Protocol TCP -LocalPort 8000,4444,4445 -RemoteAddress 192.168.31.1 -Profile Any
```

Если меняли адрес (`--host`) или порты, скорректируйте правило. Не отключайте
брандмауэр целиком. После установки удалите исключение:

```powershell
Get-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" | Remove-NetFirewallRule
```

### Прошивка запущена, но `permanent OpenWrt was not verified`

Сообщение `sysupgrade уже запущен` означает, что повторять запись нельзя. То, что
роутер не нашёлся, само по себе не доказывает неудачу. Подключитесь к постоянной сети
или к LAN-порту кабелем и выполните **только проверку**, указав `resume.json` именно
этого запуска (путь напечатан установщиком):

```powershell
py -3 install.py --verify-only ".\install-ДАТА-ВРЕМЯ\resume.json" --verify-interface 12
```

Не используйте манифест другого роутера или другой установки.

### Забыт пароль постоянной сети Wi-Fi

Подключитесь к **LAN-порту** кабелем, получите адрес автоматически и откройте
`http://192.168.1.1`. В LuCI: **Network → Wireless → Edit → Wireless Security**,
задайте новый пароль, затем **Save & Apply**. Заводской сброс не нужен.

## 7. После установки

- Если в логе было `root password=unset`, задайте пароль администратора:
  **System → Administration**.
- Проверьте страну и настройки безопасности Wi-Fi.
- Сохраните настройки: **System → Backup / Flash Firmware → Generate archive**.
- Храните папку `install-*` в закрытом месте: там резервные копии разделов,
  `firstboot.tar.gz` и `resume.json` с паролями, сеансовыми секретами и данными
  устройства. Не публикуйте их и полные логи без удаления секретов. В Windows права
  наследуются от папки, а не задаются `chmod`, поэтому выбирайте папку без общего
  доступа.

## Возврат на заводскую прошивку

Скачайте официальный заводской образ, SHA-256 которого одобрен в профиле устройства
([список](docs/technical.md#getting-the-images)). Затем из установленного OpenWrt:

```sh
python3 revert.py --device rd03v2 /путь/к/заводскому-образу.bin --interface ИНТЕРФЕЙС
```

В Windows: `py -3 revert.py ...`, этот путь на реальном роутере ещё не проверялся.
Дополнительные параметры: `--transport wired`, `--root-password ПАРОЛЬ`, `--dry-run`.
Подтверждение стирания нужно ввести словом `RESTORE` латиницей.

`revert.py` проверяет заводской образ, скачивает образы RAM-системы, переводит роутер
в RAM, восстанавливает заводскую прошивку и убеждается, что вернулся мастер настройки.
Для возврата используйте его, а не повторный запуск прошивки: после `sysupgrade`
заводской A/B-резерв уже стёрт (см. [NOTICE](NOTICE)).

## Дополнительные инструменты

| Команда | Назначение |
|---|---|
| `python3 release.py --device rd03v2` | Показать последний релиз и нужные файлы. |
| `python3 release.py --device rd03v2 --download --wifi --dest images` | Скачать и проверить образы. |
| `python3 attach.py --bind АДРЕС --peer АДРЕС_РОУТЕРА --session-token ТОКЕН 'id'` | Переподключиться к обратному каналу прерванного запуска. |
| `python3 selftest.py` | Проверки без роутера (Linux). В Windows: `py -3 -m unittest test_hostnet test_windows test_i18n`. |

`probe.py` в Windows не проверялся; его автоматическое переподключение к Wi-Fi работает
только в Linux. Прерванные запуски, отдельные стадии и восстановление описаны в
[технической документации](docs/technical.md) (на английском).
