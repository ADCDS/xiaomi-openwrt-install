# xiaomi-openwrt-install

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md) · [Português (Brasil)](README.pt-BR.md) · [Техническая документация (English)](docs/technical.md)

Установка OpenWrt на поддерживаемые роутеры Xiaomi без UART и пайки, а также
возврат установленного роутера на одобренный заводской образ. Работает из Linux
и из Windows 10/11 без WSL.

Установщик получает root через
[задокументированную цепочку уязвимостей `cab_meshd`](https://github.com/ADCDS/xiaomi-ax3000t-cabmeshd-disclosure#combined-v1--v2-capuci-exploit),
проверяет плату, NAND и разметку, скачивает образы OpenWrt для вашего устройства,
загружает временную RAM-систему и записывает постоянную прошивку.

> Прочитайте [NOTICE](NOTICE). Используйте установщик только на своём роутере.

## Поддерживаемое устройство

Поддерживается только Xiaomi AX3000T **RD03v2** (Qualcomm IPQ5018). Установка OpenWrt и возврат к заводской прошивке проверены на версиях **2.0.28** и **2.0.12**. См. [профиль устройства](devices.py).

## Что проверено

См. [результаты испытаний для разных систем, подключений и версий прошивки](docs/maintenance.ru.md#что-проверено).

## 1. Подготовка

- Обеспечьте стабильное питание роутера. Не отключайте его во время записи.
- Сохраните нужные заводские настройки: сброс удалит конфигурацию и пароли.
- Изолируйте подключение: к заводской и временной сети не должны подключаться
  посторонние устройства. Пароль временной сети общеизвестен, а у root во
  временной RAM-системе пароля нет.
- Отключите VPN и другие сети, чьи адреса могут совпасть с адресами роутера.

Скачайте репозиторий и откройте терминал в его папке:

```sh
git clone https://github.com/ADCDS/xiaomi-openwrt-install.git
cd xiaomi-openwrt-install
```

### Linux

Нужен Python 3.9 или новее:

```sh
sudo apt install sshpass openssl
```

### Проверка установленной системы с ключом SSH

Если веб-интерфейс и ручной вход по SSH с ключом работают, повторите только
проверку, без новой прошивки:

```sh
python3 install.py --verify-only /path/to/install/resume.json \
  --verify-interface en0 --verify-host 192.168.1.1 \
  --verify-ssh-key ~/.ssh/id_ed25519
```

Укажите свой интерфейс и путь к закрытому ключу. Вместо пути можно указать
`agent`, чтобы использовать ssh-agent или стандартную конфигурацию OpenSSH.
Зашифрованный ключ сначала загрузите через `ssh-add`. Нужны системный OpenSSH
и доверенный ключ хоста для этого адреса: сначала подтвердите его при ручном
входе по SSH. Проверяются модель, постоянные разделы, версия и записанная
перезагрузка, затем обновляется локальный `resume.json`. Эти параметры требуют
`--verify-only` и не меняют аутентификацию при прошивке.

### Windows 10/11

Установите Python 3.9 или новее с
[python.org](https://www.python.org/downloads/windows/), включая launcher `py`.
Можно скачать ZIP репозитория вместо `git clone`. Откройте PowerShell в папке с
`install.py` и установите зависимости **пока есть доступ к Интернету**:

```powershell
py -3 -m pip install -r requirements-windows.txt
py -3 install.py --list-interfaces
```

В Windows используйте `py -3` вместо `python3`. В примерах замените `12` на индекс своего адаптера. Оставьте IPv6 включённым, чтобы установщик мог найти роутер после перезагрузки.

## 2. Образы и Интернет

По умолчанию используется последний опубликованный релиз [OpenWrt для RD03v2](https://github.com/ADCDS/openwrt-xiaomi-ax3000t-rd03v2) с аппаратным ускорением NSS. Последняя сборка `standard` без NSS — v1.14.

Пока есть интернет, скачайте и проверьте образы с помощью `--dry-run`. Для `--offline` укажите тег релиза с помощью `--release ТЕГ`. В кэше должны быть образы для выбранного подключения. См. [проверку образов (на английском)](docs/technical.md#verifying-openwrt-releases).

В примере ниже Windows загружает образы для Wi-Fi. Для проверки образов Ethernet замените `--transport wifi` на `--transport wired`.

```powershell
py -3 install.py --transport wifi --dry-run
```

## 3. Сброс и подключение

1. Выполните аппаратный сброс кнопкой Reset.
2. Подключитесь к порту **LAN** (не WAN) кабелем или к открытой заводской сети
   Wi-Fi вида `minet_rd03_XXXX`.
3. **Не проходите мастер настройки Xiaomi** ни в браузере, ни в Mi Home.
   Автоматически открывшуюся страницу можно закрыть.
4. Отключите VPN и лишние подключения. При установке по Wi-Fi отсоедините кабель
   и не позволяйте компьютеру переключиться на домашнюю сеть.
5. Проверьте адрес: должен быть `192.168.31.x`, а `http://192.168.31.1` должен
   открываться. Сообщение «Без доступа к Интернету» здесь нормально.

## 4. Установка

```sh
python3 install.py
```

В Windows, указав свой адаптер:

```powershell
py -3 install.py --interface 12 --configure
```

Если финальная проверка проходит по Wi-Fi, укажите имя постоянной сети, пароль из 8–63 печатных символов ASCII и код страны использования. Чтобы оставить Wi-Fi выключенным, выберите проводной интерфейс для проверки с помощью `--verify-interface`. Пароль root задаётся отдельно.

Как передать пароли через переменные окружения, см. в [разделе о настройке при первом запуске (на английском)](docs/technical.md#first-boot-configuration).

Язык подсказок выбирается по языку системы. Чтобы выбрать русский вручную, укажите `--lang ru`. Диагностические сообщения выводятся на английском.

## 5. Перезагрузки: три разные сети Wi-Fi

Оставьте терминал открытым. По подсказке установщика переключитесь с заводской сети на временную, а после записи подключитесь к постоянной сети, которую вы настроили.

Если запуск прервался после предварительных проверок, установщик напечатает команду для
продолжения. Раньше этого момента он её не печатает: прошивка ещё не записана, так что
начать заново можно, если одноразовый триггер не был израсходован. По журналу этого не
определить; если триггер уже сработал, эксплойт откажется, и вернуть его может только
заводской сброс. После
потери связи роутер может подключаться снова в течение до 30 минут.

После сообщений `flash-started` или «не отключайте питание» **не отключайте
питание, не сбрасывайте роутер и не запускайте этап прошивки повторно**.

## 6. Частые ошибки

Большая часть этого раздела взята из реальной установки из Windows 10
([alexsys87](https://github.com/alexsys87/xiaomi-openwrt-install)).

### Кириллица в имени интерфейса и `Interface ... not found`

В PowerShell имя при копировании может искажаться. Используйте числовой индекс из
`--list-interfaces`, например `--interface 12`.

### `--interface ... не совпадает с маршрутом к ...`

Система направляет трафик к роутеру через другой адаптер, а `--interface` не меняет
маршрутизацию. Установщик останавливается до использования одноразового триггера.
Подключитесь к нужному роутеру, отключите VPN и конкурирующую сеть, проверьте адрес
(`192.168.31.x`) и выберите правильный интерфейс.

### `V2 CAP path is unavailable (netmode=4)` и `inited=1`

Роутер уже настроен. Выполните заводской сброс, подключитесь к заводской сети и
**не проходите мастер Xiaomi**. Если ошибка повторяется после корректного сброса,
сохраните лог и создайте Issue; не пытайтесь обходить проверки.

### GitHub: `The handshake operation timed out`

Не удалось получить сведения о релизе по HTTPS. С роутером это не связано: в
заводской сети часто нет Интернета. Если образы скачаны заранее, используйте
`--release vX.Y.Z --offline` из раздела 2. Сам по себе `--offline` загрузку не
заменяет. Повторный сброс из-за этой ошибки не нужен.

### Пароль WPA2 не принимается

Переключите раскладку на английскую. Нужно 8–63 печатных символа ASCII. Эта проверка
выполняется до начала записи, поэтому роутер не затронут.

### Обратное подключение не приходит: брандмауэр Windows

Симптом: `root-доступ не получен` или `no root shell`. Сначала проверьте сеть и
маршрут. Если блокируется входящее подключение от роутера, разрешите `python.exe` и
нужные порты только от заводского адреса. Заводскую сеть Windows может считать
общедоступной, поэтому правила только для частных сетей может не хватить. В
PowerShell **от имени администратора**:

```powershell
$python = py -3 -c "import sys; print(sys.executable)"
New-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" -Direction Inbound -Action Allow -Program $python -Protocol TCP -LocalPort 8000,4444,4445 -RemoteAddress 192.168.31.1 -Profile Any
```

Если меняли адрес (`--host`) или порты, скорректируйте правило. Не отключайте
брандмауэр целиком. После установки удалите исключение:

```powershell
Get-NetFirewallRule -DisplayName "Xiaomi OpenWrt installer" | Remove-NetFirewallRule
```

### Прошивка запущена, но `permanent OpenWrt was not verified`

Если запись уже началась, используйте `resume.json` именно этого запуска и выполните [только проверку](docs/maintenance.ru.md#проверка-после-записи).

### Забыт пароль постоянной сети Wi-Fi

Пароль беспроводной сети можно [сменить в LuCI](docs/maintenance.ru.md#забыт-пароль-постоянной-сети-wi-fi), подключившись по кабелю.

## 7. После установки

Задайте пароль администратора, если он ещё не установлен. Храните резервные копии и `resume.json` в закрытой папке. См. [действия после установки](docs/maintenance.ru.md#после-установки).

## Обновление установленной системы

По умолчанию `updater.py` сохраняет настройки. См. [обновление OpenWrt и продолжение прерванного обновления](docs/maintenance.ru.md#обновление-установленной-системы).

После проверенного обновления `updater.py` снова ставит пакеты, которые вы
устанавливали сами (`--no-reinstall` отключает это). Файлы, не принадлежащие ни
одному пакету, он ищет только с `--auto-keep`. Подробнее (на английском):
[docs/packages.md](docs/packages.md).

## Веб-мастер

```sh
python3 gui/app.py
```

Локальный пошаговый мастер на английском, русском, упрощённом китайском и бразильском
португальском: пробный прогон, отслеживание этапов и журнал в реальном времени. Как и
`updater.py`, работает и в Windows 10/11, и в Linux.
См. [gui/README.md](gui/README.md).

## Возврат на заводскую прошивку

Для возврата используйте `revert.py` и заводской образ, одобренный для этой модели. См. [инструкцию по восстановлению прошивки](docs/maintenance.ru.md#возврат-на-заводскую-прошивку).
